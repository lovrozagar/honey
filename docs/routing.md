# Routing

A route is a method, a path and a handler. The route builder takes the route's input, output, errors and
metadata before `.handler()`, and the handler's `ctx` is typed from all of them. Path parameters (`/users/:id`) are
strings until an input schema validates them. A trailing slash is normalized, so `/users` and `/users/` are one route.

WebSocket routes take `ws(app, path)` from `@lovrozagar/honey/ws`, and `serveOpenApi` and `serveManifest` from
`@lovrozagar/honey/openapi` mount the generated document and the route manifest. A dotted `operationId`
(`users.list`) groups the generated SDK's methods into resources and names the CLI's and MCP's commands.

## Example

```ts
import { honey } from "@lovrozagar/honey"
import { serveOpenApi } from "@lovrozagar/honey/openapi"
import { scalar } from "@lovrozagar/honey/openapi/scalar"

const app = honey()

app
	.get("/users/:id")
	.meta({ operationId: "users.get", summary: "One user", tags: ["users"] })
	.handler((ctx) => ctx.res.json("ok", { id: ctx.params.id }))

app.delete("/users/:id").handler((ctx) => ctx.res.noContent())

serveOpenApi(app, { title: "Users", version: "1.0.0", docs: scalar })
```

## Reference

| Value                                                    | Default   | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Watch for                                                                                                                                    |
| -------------------------------------------------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `.get/.post/.put/.patch/.delete/.options/.head(path, …)` | —         | registers a route for that method + path                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | a builder without `.handler()` is reported at finalize                                                                                       |
| path pattern `/a/:id`                                    | —         | named params matched by `pattern.ts`; value typed by the input schema                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | params are strings until the input schema validates them                                                                                     |
| trailing slash                                           | canonical | redirected/normalized per `request-path.ts`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | a double registration with/without slash is one route                                                                                        |
| `.meta({ … })`                                           | `{}`      | attaches OpenAPI operation meta; `extensions: { "x-*" }` reaches operation extensions                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | only `x-`-prefixed extension keys are allowed                                                                                                |
| `.meta({ extensions: { "x-realtime": true } })`          | off       | marks the operation as a realtime/resume endpoint                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | honey does not emit `x-realtime` itself; the consumer opts in                                                                                |
| `operationId` (dotted)                                   | derived   | groups SDK resources (`users.list`) and names CLI/MCP verbs                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | the dotted name is the resource tree; keep it stable                                                                                         |
| sub-app `mergeTree` / mount                              | —         | mounts a sub-app's tree under a prefix                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | an unknown route under a mount marks the tree stale (finalize)                                                                               |
| `ws(handle, path)`                                       | —         | subpath function from `./ws`; a WebSocket route on `handle` (the app or any chain: its ctx, scoped middleware and base path as an HTTP route gets them) with its own finalize plan (see `realtime.md`). Not an app method                                                                                                                                                                                                                                                                                                                                                                                                                                              | upgrade is adapter-specific; the plan is matched separately                                                                                  |
| `serveOpenApi(handle, options)`                          | —         | subpath function from `./openapi`; mounts `${path}.json/.yaml/.yml` (+ an optional `docs` UI at `docsPath`) on `handle` as internal GETs (`meta({ internal: true })`, left out of the document/manifest/`$routes`), served with ETag + `Cache-Control: no-cache` + 304, cached per graph epoch; returns the handle. `handle` is the app or any middleware chain, so `serveOpenApi(app.use(auth), { path: "/private/spec" })` serves behind custom middleware at a custom path (this subsumes a separate `spec()`). Not an app method. `docs` is the page itself, imported from `./openapi/scalar` or `./openapi/swagger`, so an app that shows no page bundles neither | a taken path is the ordinary duplicate-route error (no `/reference` fallback); the docs UI points at `stripPrefix + basePath + ${path}.json` |
| `serveStaticOpenApi(handle, options)`                    | —         | subpath function from `./openapi/static`; serves a document the app did not generate (`json`/`yaml` from `{ inline }`, `{ asset, binding? }`, `{ url, init? }` or a loader) at `${path}.json` / `.yaml` / `.yml`, or at `jsonPath`/`yamlPath` outright, with an optional `docs` page; internal + served GETs carrying the caller's `meta`, answered with a strong ETag and `cacheControl` (default `no-cache`). Imports none of the generator                                                                                                                                                                                                                          | a document is loaded once per isolate and never refreshed; an asset or loader failure is a 500, a URL failure a 502                          |
| `serveManifest(app, options?)`                           | —         | subpath function from `./openapi`; mounts `path` (default `/manifest.json`) as an internal GET serving the route manifest at published visibility; returns the app                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | unpublishable meta keys and `internal` routes are dropped                                                                                    |
