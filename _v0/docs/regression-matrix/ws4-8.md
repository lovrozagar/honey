# Regression matrix: workstreams 4–8

Streaming, Node adapter and WebSockets, the realtime bus, security middleware, input and output.
Tests live in `packages/core/tests/regression/ws4-8/`:

- `node-adapter.regression.test.ts` drives `node-fixture.ts` under plain `node` through the real
  Node adapter (`serve()`). Crash findings assert that the fixture process is still alive.
- `in-process.regression.test.ts` runs through `app.fetch`, or a Node server inside the test
  process, and a real `node:http` upstream for the proxy findings.

Every test below fails on `3ab88ce` and passes on HEAD; each was run against both trees. Where a test
bundles several sub-cases of one finding, each sub-case was checked against `3ab88ce` on its own.
To re-run them against `3ab88ce`, copy the whole `ws4-8/` directory (the fixture and the harness
come with it), following the [README](README.md).

Scope: Critical, High and Medium findings, plus one cheap Low. Findings in the unexported realtime
protocol modules were deleted with those modules under the realtime decision and are out of scope.

`in-process` = `in-process.regression.test.ts`, `node` = `node-adapter.regression.test.ts`.
