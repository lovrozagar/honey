# Middleware

Middleware runs in registration order around the handler, may short-circuit, and may extend `ctx` for
everything below it. A `MiddlewareFn<Requires, Adds>` (or `createMiddleware`) types what it reads and what it
adds. Call `await next()` to run the rest of the chain: it
returns the downstream response, synchronously when everything below ran synchronously.

The edge set is plain middleware, each from its own subpath, so an app bundles only what it imports: `cors`,
`secureHeaders`, `csrf`, `rateLimit`, `compress`, `requestId`, `timeout`, `bodyLimit`, `serverTiming`, `poweredBy`
and `ipRestrict`. Keyed limits read `ctx.ip`, the platform's peer address; honey never trusts an `X-Forwarded-For`
header, so behind your own proxy read the header your proxy sets in your own code.

## Example

```ts
import { type MiddlewareFn, honey } from "@lovrozagar/honey"
import { cors } from "@lovrozagar/honey/cors"
import { rateLimit } from "@lovrozagar/honey/rate-limit"
import { secureHeaders } from "@lovrozagar/honey/secure-headers"

type UserCtx = { user: { id: string } | null }

const withUser: MiddlewareFn<{ req: Request }, UserCtx> = (ctx, next) => {
	const token = ctx.req.headers.get("authorization")
	return next({ user: token === null ? null : { id: "u1" } })
}

const app = honey()
	.use(secureHeaders())
	.use(cors({ origin: ["https://app.example.com"], credentials: true }))
	.use(rateLimit({ limit: 100, windowMs: 60_000 }))
	.use(withUser)

app.get("/me").handler((ctx) => ctx.res.json("ok", { user: ctx.user }))
```

## Reference

| Value                                   | Default               | What it does                                                                                                                                                                                                                                                                                                                             | Watch for                                                                                                                                                                                                                                                                                |
| --------------------------------------- | --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `createMiddleware` / `defineMiddleware` | —                     | a typed middleware that can extend `ctx` and short-circuit                                                                                                                                                                                                                                                                               | extending `ctx` changes the handler type downstream                                                                                                                                                                                                                                      |
| `next()`                                | —                     | runs the rest of the chain and returns the downstream response; typed `MaybePromise<MiddlewareResult>` — synchronous when everything downstream ran sync (the sync-spine win, bit 02)                                                                                                                                                    | **always `await next()`** (works sync or async); `next().then(...)` is now a compile error, not a runtime crash                                                                                                                                                                          |
| `cors(options)`                         | —                     | CORS headers + preflight                                                                                                                                                                                                                                                                                                                 | credential reflection with `*` origin is rejected under the adversarial gate                                                                                                                                                                                                             |
| `secureHeaders(options)`                | sane set              | HSTS, X-Content-Type-Options, frame, referrer, etc.                                                                                                                                                                                                                                                                                      | overriding a header to a weaker value is the user's choice, documented                                                                                                                                                                                                                   |
| `csrf(options)`                         | —                     | CSRF origin/token check                                                                                                                                                                                                                                                                                                                  | pairs with cookie settings; GET is exempt                                                                                                                                                                                                                                                |
| `rateLimit(options)`                    | off                   | **fixed-window** limiter (pinned); default key = resolved `ctx.ip`; emits `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset` (epoch seconds) + `Retry-After` (delta seconds) on 429; `store` is a `RateLimitStore { hit(key): { count, resetAt } \| Promise<…> }`, default **bounded** in-process (LRU/TTL + max-entries) | memory store is per-process and capped (key-spray can't OOM it, H18.8); use a shared store behind multiple instances                                                                                                                                                                     |
| `compress(options)`                     | off                   | **gzip** by `Accept-Encoding` (dynamic); br is for **precompressed static** (`.br` sibling at phase c)                                                                                                                                                                                                                                   | skips already-encoded/streamed/sub-threshold bodies; BREACH default-excludes credentialed/cookie-setting answers; the edge may already compress. No dynamic br: `CompressionStream` has no quality knob and runs brotli at q11 (~55× gzip for ~2× ratio — a footgun on the request path) |
| `requestId({ trustInbound })`           | `trustInbound: false` | assigns/propagates a request id                                                                                                                                                                                                                                                                                                          | reuse an upstream id only when `trustInbound` is satisfied=>boolean`predicate; trust is cut, there is no`ctx.trustsForwarded`); default `false`always generates fresh,`validate` always applies                                                                                          |
| `timeout(ms)`                           | off                   | aborts a slow handler                                                                                                                                                                                                                                                                                                                    | a streaming response needs no timeout                                                                                                                                                                                                                                                    |
| `bodyLimit(bytes)`                      | app default           | caps request body                                                                                                                                                                                                                                                                                                                        | an unbounded body is a DoS vector                                                                                                                                                                                                                                                        |
| `serverTiming()`                        | off                   | `Server-Timing` header                                                                                                                                                                                                                                                                                                                   | adds timing visibility; off by default                                                                                                                                                                                                                                                   |
| `poweredBy(value?)`                     | off                   | `X-Powered-By`                                                                                                                                                                                                                                                                                                                           | off by default; opt in                                                                                                                                                                                                                                                                   |
| `ipRestrict(policy)`                    | —                     | allow/deny by `ctx.ip` (the canonical platform peer; trust is cut, so no `trustProxy` and no X-Forwarded-For — a spoofed header cannot change the keyed IP)                                                                                                                                                                              | matches against the real peer only; behind a proxy, restrict at the proxy                                                                                                                                                                                                                |
