# Workstreams 1–3: route model, middleware finalize, request normalization

Findings from the `3ab88ce` review (workstreams 1–3) mapped to their guards. "Fails on
3ab88ce" was checked by running the same test file against the extracted `3ab88ce` source (see
[README.md](README.md)); every "yes" failed there with the symptom the finding describes. Test
files are under `packages/core/tests/regression/`:

- `ws1-route-model.regression.test.ts` (WS1)
- `ws2-middleware.regression.test.ts` (WS2)
- `ws3-request.regression.test.ts` (WS3)

## Regression found while building this matrix (fixed)

**GW-OWN-ROUTES (high, fixed).** A gateway booted from a `codegen.mergeTree` tree that registers
routes of its own threw `Route tree out of date — regenerate it` on every request: the plugin
wrote the tree from the `mergeTree` source alone. Generation now builds the gateway's tree from
the merged downstream tree plus the gateway app's own routes (`_gatewayTree`); its root
wildcards stay out of the tree as the catch-all the downstream leaves delegate to, and an own
route that is also a downstream route fails generation by name. Guarded by
`gw-own-routes.regression.test.ts`, which runs the real `generateAndWrite` over a downstream-only
`routes.gen.ts` (what such a gateway has committed) and fails before the fix with the error
above; the e2e gateway app (`e2e/apps/gateway`) now has this shape on every runtime.
