# dx — observability

A honey server reports what it does: every server-side line goes through a pluggable pino-compatible logger with a per-request child; every server error reaches an `onError` hook that never delays the response; an optional request log records each request; every request carries a validated request id; and optional OpenTelemetry-compatible tracing produces one nested trace per request with no tracing dependency in core. Nothing is swallowed silently, nothing private is logged, and with nothing configured the per-request cost stays within the perf budget. Modeled on flare's observability (bit 16), scoped to an API framework — no browser, so no dev log bridge; honey adds gateway/proxy propagation and SSE/WS span lifecycle.

## Tracing (`otelAdapter({ tracer })`, subpath export)

Structural `Tracer` — core imports no tracing package. `otelAdapter(api, { trustInbound?, onError? })` takes the app's own OpenTelemetry API **as a value** (bit-07 Ruling 5 / F1): it uses **`{ trace, context }`** only — **`propagation` is dropped** (its default propagator is a no-op until an SDK registers one, and the trust gate must validate `traceparent` itself, so core parses it in `traceparent.ts`). honey imports no `@opentelemetry/api`, so the `./telemetry` subpath is plain tree-shaking, not an optional-peer isolation; passing the app's own instance guarantees one shared OTel singleton. Real `@opentelemetry/{api,sdk-trace-base,core}` are **devDependencies only** (F11) — one `otel.test` case drives a real `BasicTracerProvider`+`InMemorySpanExporter` and `traceparent.test` cross-checks the parser against `W3CTraceContextPropagator`; `test:packaging`+`test:build` confirm no runtime/bundle leak.

> **Superseded by the trust cut (H23, bit 03):** `trustProxy` is removed, so every "`trustProxy ≥ 1`" gate below — reusing an inbound request id, continuing an inbound `traceparent` — is reconciled at phase (b)/(f). The replacement is pinned there (an inbound id/traceparent is never trusted by default; reuse/continue is opt-in by explicit configuration, never a proxy-count), not by `trustProxy`.

Interface: `startSpan(name, attributes, parent?) → { setAttribute, setStatus, recordException, end }`, optional `run(span, fn)`.

| nested tree (onion, F3/F6) | the root span is **named semconv `{method} {route}`** (just `{method}` when no route matched — a fixed `http.request` would collapse every route into one span-list entry), SpanKind SERVER, started in dispatch before routing; attrs `http.request.method`, `url.path` (no query), `http.route`=**the route pattern** (low cardinality, not the raw path), `honey.route_id`=route id, `http.response.status_code`; status ERROR on 5xx only. | explicit parenting | the parent is passed explicitly, never via an async context manager (Workers has none, Bun partial); `run(span, fn)` sets OTel's active context only so app instrumentation nests under honey's spans | `telemetry/otel.test.ts` |
| traceparent, trust-gated (F4/F5) | strict W3C level-1 parse in core `traceparent.ts` (lowercase hex, version `00`=55 chars, higher version read by first 55 + `-` boundary, `ff` invalid, all-zero trace/span id invalid; `tracestate` kept only beside a valid parent, ≤32 members/512 chars else dropped). `otelAdapter(api, { trustInbound })` (b1) satisfied + valid → **continue** (remote parent + tracestate); untrusted + valid → **new trace + link** to the inbound; malformed → fresh, no link; a throwing predicate → untrusted + warn; no tracer → never read. **Request id and trace id stay DISTINCT (F5)** — they are not collapsed (b1 keeps the request id honey's own, server-fresh by default so a client can't pick it anyway); `requestId` sets `honey.request_id` on the root and the logger child binds `trace_id`+`span_id` (correlation, not equality) | `telemetry/traceparent.test.ts` |
| outbound propagation | `proxy`/gateway forwards `traceparent` for the current span | `telemetry/traceparent.test.ts` |
| span lifecycle (F8) | the root ends when the body finishes or is cancelled (not at headers; HEAD/101/buffered/no-body end at once); a disconnect sets `honey.outcome="aborted"` with status left unset (a client leaving is not a server error, and OTel has no aborted status). ## Privacy (enforced by tests)

No cookie, `Authorization`, `Set-Cookie`, query string, request body, or handler input appears in any log field or span attribute. Paths are logged without the query. Route ids, not raw paths, name spans. A grep of every log/span call site for `cookie`/`authorization`/`query`/`body` finds nothing that carries them.

## Consumer-pinned cases (anyrow)

The oracle must include, because real consumers depend on them and honey's own suite may not:
- **response-returning `app.onError`** — a handler that returns a `HoneyError` with a status and a header (e.g. `Retry-After`) maps the response exactly, and the error-key's i18n is applied on the default response path; returning `undefined` falls through to the projector. (anyrow `createDbErrorHandler`.) `errors/on-error.test.ts`.
- **`trustInbound`-off requestId** — with `trustInbound: false` (the default), an inbound `x-request-id` is **not** reused (a fresh id is generated); with `trustInbound: true` or a predicate that passes, a safe inbound id is reused. (anyrow gateway→service propagation.) `middleware/request-id.test.ts`.

## Configuration matrix (the proof)

Every combination of `logger` (default / custom / off) × `onError` (absent / present) × `requestLog` (off / on) × `tracer` (absent / present) × `trustInbound` (false / true), in dev and prod — 96 in-process cases. Each serves a request, a handler error, a streamed/SSE response, and a gateway/proxy hop, and asserts: status + body identical to an unconfigured server; nothing throws; `x-request-id` present and safe; each line lands exactly where this contract says; `onError` fires exactly once per error; the span set matches; nothing private leaks. `telemetry/observability-matrix.test.ts`.

## Cost

Unconfigured observability stays within 2% of the pre-observability baseline (the default logger checks the level before building fields; no span object exists without a tracer). `telemetry/bench-observe` + the perf gate.
