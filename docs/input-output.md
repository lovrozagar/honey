# Input and output

`.input()` declares what a route reads, each source validated by a Standard Schema (zod, valibot, arktype):
`params`, `search`, `headers`, `cookies`, and one body, `json`, `form` or `binary`. A request that fails validation is
answered 400 with the failing fields, and `ctx.input` holds the parsed values, typed.

`.output()` declares what it answers, the media type as the outer key and the status as the inner one. Any media
type works, `image/gif` or `application/zip` included, and a status may declare its response headers, which reach the
OpenAPI document and the SDKs' typed accessors. An outer key that is no `type/subtype`, `headers` or `redirect`, or an
inner key that names no status (`orders` where `ok` was meant), is a type error. Untyped, it fails where the app is
documented (`honey generate`, `generateOpenApi`, `serveOpenApi`), naming the route and the key; serving requests never
checks it. `ctx.res` builds the answer: `json`, `text`, `html`, `binary`, `sse`, `redirect`, and `raw` for any
`Response`. A status is always a key, never a number: `ctx.res.json("created", body)`, and
`ctx.res.redirect("found", url)` at a 3xx key. Under `.output()` the handler may return only a declared media type at
one of its status keys, no content, or a redirect at a key the `redirect` entry declares (`ctx.res.redirect` is gone
without one), so `raw` is gone there; `text`, `html`, `csv`, `xml` and `binary` also take a
`ReadableStream` body, sent as it comes. Status keys alone declare JSON: `.output({ ok: schema })` is
`.output({ "application/json": { ok: schema } })`, `headers` and `redirect` beside them as in the full form; the two
forms do not mix. When a route declares one 2xx status under one media type, other than an event stream, and that
status declares no headers, the handler may return the body itself, and honey answers it at that status through the
type's helper. With two success statuses or two media types, build the answer with `ctx.res`.

## Example

```ts
import { defineErrors, honey } from "@lovrozagar/honey"
import * as z from "zod"

const errors = defineErrors({})

const app = honey()

app
	.get("/books/:id")
	.input({ params: z.object({ id: z.string() }), search: z.object({ lang: z.string().optional() }) })
	.output({ ok: z.object({ id: z.string(), title: z.string() }) })
	.errors(errors, "not_found")
	.handler((ctx) => {
		if (ctx.input.params.id === "0") throw errors.not_found()
		return { id: ctx.input.params.id, title: "Dune" }
	})

app
	.post("/books")
	.input({ json: z.object({ title: z.string().min(1) }) })
	.handler((ctx) => ctx.res.json("created", { id: "b-1", title: ctx.input.json.title }))
```

## Reference

| Value                                                                                                                                                                      | Default                                                                                                                             | What it does                                                                                                                                                                                                                                                                                                                                   | Watch for                                                                                                                                               |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.input({ params })`                                                                                                                                                       | —                                                                                                                                   | typed, validated path params                                                                                                                                                                                                                                                                                                                   | validation runs after match; a bad value is a 4xx, not a miss                                                                                           |
| `.input({ search })`                                                                                                                                                       | —                                                                                                                                   | typed, validated query                                                                                                                                                                                                                                                                                                                         | arrays/coercion follow the schema, not ad-hoc parsing                                                                                                   |
| `.input({ headers })`                                                                                                                                                      | —                                                                                                                                   | typed, validated request headers                                                                                                                                                                                                                                                                                                               | header names are case-insensitive                                                                                                                       |
| `.input({ json })`                                                                                                                                                         | —                                                                                                                                   | validated JSON body; asserts content-type                                                                                                                                                                                                                                                                                                      | a wrong content-type is a 415 before validation                                                                                                         |
| `.input({ form })`                                                                                                                                                         | —                                                                                                                                   | multipart / urlencoded body                                                                                                                                                                                                                                                                                                                    | file parts follow the body-limit                                                                                                                        |
| `.input({ binary })`                                                                                                                                                       | off                                                                                                                                 | raw bytes body with a declared content-type                                                                                                                                                                                                                                                                                                    | bytes are not structurally validated; size/limit metadata may apply                                                                                     |
| body limit                                                                                                                                                                 | app default                                                                                                                         | caps body size                                                                                                                                                                                                                                                                                                                                 | an unbounded stream without a limit is a DoS vector                                                                                                     |
| `.output({ "application/json": { [status]: schema } })`                                                                                                                    | —                                                                                                                                   | typed, validated JSON response per status — **media type is the OUTER key, status the INNER** (matches v0; DX unchanged)                                                                                                                                                                                                                       | the inner status key is the SDK's return-type discriminator                                                                                             |
| `.output({ [status]: schema })`                                                                                                                                            | —                                                                                                                                   | the shorthand for the `application/json` form; `headers` and `redirect` sit beside the status keys                                                                                                                                                                                                                                             | a status key beside a media type is a type error: the forms do not mix                                                                                  |
| returning the body from `.handler()`                                                                                                                                       | —                                                                                                                                   | with one 2xx status under one media type, the handler may return the body; honey answers it at that status through the type's helper (`json`, `text`, `csv`, `binary`)                                                                                                                                                                         | not for an event stream, a status that declares headers, or two success statuses; returning nothing is still the "handler must return a Response" error |
| `.output` known media types (text/html, text/csv, text/xml, text/plain, application/pdf, application/cbor, application/msgpack, octet-stream, text/event-stream, redirect) | —                                                                                                                                   | keep helper affinity (stringify / stream / binary / redirect)                                                                                                                                                                                                                                                                                  | the 11 keep their helpers; everything else is a bytes body                                                                                              |
| `.output` open media type `` `${string}/${string}` ``                                                                                                                      | —                                                                                                                                   | any media type (image/gif, font/woff2, video/\*, application/zip) as a typed bytes body `{ format: binary }` carrying its content-type to OpenAPI/SDKs/CLI/MCP                                                                                                                                                                                 | multiple types per status negotiate via `Accept`                                                                                                        |
| `.output` per-status `headers` schema                                                                                                                                      | —                                                                                                                                   | declared, typed response headers → OpenAPI response `headers` → SDK `response.headers` accessors (ETag, Location, Retry-After, X-RateLimit-\*, Link)                                                                                                                                                                                           | an undeclared header is not in the contract                                                                                                             |
| `ctx.res.json/text/html/redirect`                                                                                                                                          | —                                                                                                                                   | build the response with helper affinity                                                                                                                                                                                                                                                                                                        | —                                                                                                                                                       |
| `ctx.res.redirect(redirectKey, url, opts?)`                                                                                                                                | —                                                                                                                                   | a bodiless answer with `Location: url` at the key's 3xx status (`found` is 302)                                                                                                                                                                                                                                                                | under `.output()`, only a key its `redirect` entry declares; no other options carry a status                                                            |
| `ctx.res.binary(statusKey, bytes, opts?)`                                                                                                                                  | `application/octet-stream`; `opts.contentType` names any other declared type, required by the types unless octet-stream is declared | typed bytes response, the bytes kept as the raw body; a `ReadableStream` goes out as it comes                                                                                                                                                                                                                                                  | bytes are a type contract, never validated; the content type still counts for the mismatch check                                                        |
| `ctx.res.sse(...)`                                                                                                                                                         | —                                                                                                                                   | `text/event-stream`; v1 types the declared event schema                                                                                                                                                                                                                                                                                        | reconnect uses `Last-Event-ID`                                                                                                                          |
| `ctx.res.raw(response)`                                                                                                                                                    | —                                                                                                                                   | untyped escape hatch; passes any `Response`, on a route without `.output()` only                                                                                                                                                                                                                                                               | invisible to OpenAPI/SDKs — declare the output and use its helper, or throw a `HoneyError` with `headers` for a refusal                                 |
| range / 206                                                                                                                                                                | off                                                                                                                                 | `Accept-Ranges` + honored `Range` for binary/stream + static                                                                                                                                                                                                                                                                                   | partial content needs the body to be seekable/sized                                                                                                     |
| `Last-Modified` / `If-Modified-Since`                                                                                                                                      | off                                                                                                                                 | time-based conditional GET beside ETag                                                                                                                                                                                                                                                                                                         | weak vs strong validator semantics                                                                                                                      |
| `defineErrors({...})` / `HoneyError`                                                                                                                                       | —                                                                                                                                   | typed error factory; serialized as honey error-key JSON. Every factory also carries honey's own keys (`not_found`, `validation_failed`, `malformed_body`, `too_many_requests`…) at the status honey answers them with, so a route declares and documents them without re-declaring them; the app's own entry for one of those keys replaces it | the error key is the SDK's typed error discriminator                                                                                                    |
| problem+json formatter                                                                                                                                                     | off                                                                                                                                 | opt-in RFC 9457 `application/problem+json`                                                                                                                                                                                                                                                                                                     | native model stays the default; opt in per app                                                                                                          |
