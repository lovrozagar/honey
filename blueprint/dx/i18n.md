# dx — i18n

ICU message interpolation + error-message localization. KEEP (bit 07 `i18n/{i18n,error-i18n}.ts`; the `let-runtime` slot is CUT, H23). anyrow applies i18n to error messages. **There is no `i18n()` locale-negotiation middleware** (v0 never had one; the draft row was a phantom, like proxy's `{target}`) — the app decides the locale in its own `resolveLocale` callback, which every consumer already passes. An Accept-Language negotiator would be a deliberate v1 addition, not shipped now.
