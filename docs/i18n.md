# Internationalization

`interpolate(template, vars, locale)` from `@lovrozagar/honey/i18n` fills `{placeholders}` and ICU `plural`
and `select` messages, formatted for the locale; `createInterpolator()` keeps its formatters between calls when you
interpolate in a loop. `errorI18n({ errors, resolveLocale })` translates error messages: set it with
`app.errorI18n(...)`, and an error's message is translated for the request's locale, its `vars` filled in.

## Example

```ts run
import { interpolate } from "@lovrozagar/honey/i18n"

const message = "{count, plural, one {# new message} other {# new messages}} for {name}"
console.log(interpolate(message, { count: 3, name: "Ada" }, "en"))
// prints: 3 new messages for Ada
```

## Reference

| Value                                               | Default | What it does                                                                                                                                                                                            | Watch for                                                                                                                                                                                       |
| --------------------------------------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `errorI18n({ errors, fieldNames?, resolveLocale })` | —       | a frozen value `{ resolveLocale, translate(error, locale) }` the `app.errorI18n(value)` setting carries; core calls `settings.errorI18n?.translate` and never imports i18n                              | the setter rejects a **raw** config with a TypeError ("pass `errorI18n({…})` from `@lovrozagar/honey/i18n`") so a missed migration fails at startup                                             |
| `interpolate(template, vars, locale?)`              | —       | fills `{placeholder}`s / ICU `plural`/`select`, locale-aware; builds one `Formatter` memo per call                                                                                                      | missing vars stay the literal placeholder, never thrown; own-key lookups only (`__proto__`/`constructor` are data)                                                                              |
| `createInterpolator()`                              | —       | `{ interpolate }` over a held per-instance memo, for a caller interpolating in a loop (anyrow's dispatch)                                                                                               | no module state; one-shots use the free `interpolate`                                                                                                                                           |
| error-message i18n                                  | —       | `on-error.ts` translates (to a **copy**) the answer for an unhandled throw and for a `HoneyError` `onError` returns; a `resolveLocale` failure logs `warn "error i18n failed"` and answers untranslated | the client gets the localized message, the operator log keeps the **raw**; the thrown error is never mutated; framework 404/405/400 stay untranslated (v0 parity — no `resolveLocale` per miss) |
